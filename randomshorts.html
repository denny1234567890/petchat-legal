randomshorts

randomshorts 는 채널 운영자 한 사람이 자기 유튜브 채널에 정보형 쇼츠 영상을 올리고, 올린 영상의 조회 성과를 확인하기 위해 쓰는 개인용 도구입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

randomshorts is a personal tool used by a single channel owner to upload short informational videos to their own YouTube channel and review their performance. It is not offered to the public.

개인정보처리방침 (Privacy Policy)

사용하는 Google 데이터
이 앱은 채널 운영자 본인이 동의한 Google 계정에 대해서만 아래 권한을 씁니다.

  • YouTube 동영상 업로드 (youtube.upload): 운영자가 만든 영상을 운영자의 채널에 올립니다.
  • YouTube 계정 정보 읽기 (youtube.readonly): 업로드한 영상의 상태를 확인합니다.
  • YouTube 분석 읽기 (yt-analytics.readonly): 업로드한 영상의 조회수 등 성과 지표를 확인합니다.

보관과 공유
인증 토큰과 성과 지표는 운영자의 개인 컴퓨터에만 저장됩니다. 제3자에게 팔거나 넘기지 않으며, 광고나 다른 목적에 쓰지 않습니다. 다른 사람의 Google 계정 데이터는 수집하지 않습니다.

권한 철회
Google 계정 → 타사 액세스에서 언제든지 이 앱의 접근 권한을 철회할 수 있습니다.

Google API 사용 정책 준수
이 앱이 Google API 에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
